Heimdallone v2 is a multi-tenant SaaS platform covering HR, time, payroll, finance,
and operations. Every module is built as a **tenant-configurable capability** — no
single company, country, or workflow is hardcoded.

## Who uses Heimdallone

- **Admins** configure the tenant, manage people, and run payroll.
- **Managers** see their team — approvals, scoped reports, team data.
- **Employees** use self-service — payslips, leave, requests, their own records.
- **Auditors** have read-only access for review and compliance.
