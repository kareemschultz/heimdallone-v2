Welcome to the **Heimdallone** documentation. Heimdallone v2 is a multi-tenant SaaS
platform for HR, payroll, time, finance, and operations across many businesses,
countries, and operating models.

<Callout title="How these docs are organised">
  Docs are **module-based** and **role-aware**. Where a workflow differs by role,
  each view (Admin / Manager / Employee / Auditor) is documented separately.
  Status labels tell you what is live vs staged.
</Callout>
