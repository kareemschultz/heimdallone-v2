Finance is a **coordination layer**: it reads payroll actuals, approved project
time, and contract rates to produce cost reports and budgets, and owns the general
ledger. It links to other modules but never mutates them.

  The ledger links to payroll via soft references and never writes payroll records.
  Cost reports are read models built from payroll and project actuals.
</Callout>
